# General Trivia bootstrap kit

Drop these files into a repo that must look like the trivia page.

1. Treat `DESIGN.md` as the source of truth.
2. Put `tokens.css` on `:root` (or import it first).
3. Keep `tokens.json` in sync — never edit it apart from `tokens.css`.
4. Changes belong in `DESIGN.md` first, then tokens, then product CSS.

Not for Radiant Art Room.
